# 近隣1km 飲食店マップ (RestaurantSearch-app)

現在地（GPS）から半径1km以内にある飲食店を、ホットペッパーグルメ Webサービス（API）を用いて検索・一覧表示するWebアプリケーションです。

---

## 📌 主な機能・特徴

- **📍 現在地からワンクリック検索**
  - ブラウザの Geolocation API を利用して高精度な位置情報（緯度・経度）を取得し、半径1km（徒歩10〜15分圏内）の飲食店を自動検索します。
- **📋 充実した店舗一覧テーブル**
  - **店舗名 / ジャンル / キャッチコピー**: お店の名前と料理ジャンル、特徴を表示
  - **営業時間 / 定休日**: 営業スケジュールを一目で確認
  - **標準価格帯（目安・平均）**: ディナー・ランチ等の平均予算帯を表示
  - **Googleマップ連携**: クリック一つで該当店舗のGoogleマップを開き、ルート検索やクチコミを確認可能
- **🔐 安心・手軽なAPIキー管理**
  - ユーザー自身のホットペッパーAPIキーを画面右上の「APIキー設定」モーダルから登録・更新可能。
  - APIキーはお使いのブラウザ内（LocalStorage）にのみ安全に保存され、外部サーバーへ送信されることはありません。
- **⚡ ゼロ依存のローカル中継サーバー（Node.js標準）**
  - リクルートWEBサービスのJSONP提供終了に伴うCORS制約を解消するため、Node.js標準モジュールのみで動く軽量Webサーバー＆プロキシ（`server.js`）を同梱しています。追加の `npm install` は不要です。
- **📱 レスポンシブ＆モダンUI**
  - Tailwind CSS を採用し、PC・スマートフォン・タブレット問わず直感的に操作できます。

## 🚀 利用方法

### 1. ホットペッパーAPIキーの取得（初回のみ・無料）
1. [リクルートWEBサービス 新規登録ページ](https://webservice.recruit.co.jp/register/) にアクセスします。
2. 会員登録を行い、発行された「APIキー」をコピーします。

### 2. アプリの起動

以下のいずれかの方法でアプリを起動します。

#### 方法A: バッチファイルから起動（Windows推奨）
フォルダ内にある `start.bat` をダブルクリックするだけで、サーバーが起動しブラウザが自動的に開きます。

#### 方法B: コマンドラインから起動
ターミナルで以下のコマンドを実行します（Node.js が必要です）。
```bash
node server.js
# または
npm start
```
起動後、ブラウザで `http://localhost:3000` を開きます。

---

### 3. アプリの操作手順
1. 画面右上の **「APIキー設定」** ボタンをクリックします。
2. 取得したホットペッパーAPIキーを入力し、**「保存する」** をクリックします。
3. **「現在地で検索する」** ボタンをクリックします。
4. ブラウザで「位置情報の利用を許可しますか？」と尋ねられたら **「許可」** を選択します。
5. 半径1km以内の飲食店一覧が表示されます。気になる店舗の「マップを開く」ボタンを押すとGoogleマップにジャンプします。

---

## ⚠️ ご利用上の注意

- 位置情報の取得には、ブラウザの「位置情報の利用許可」が必要です。
- APIの利用規約に従い、ホットペッパーグルメWebサービスのクレジット表記をフッターに明記しています。
